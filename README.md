# DC Refrigeración

Landing de demostración para **DC REFRIGERACIÓN SERVICIO TÉCNICO**.

## Cómo correrla

```bash
npm install
npm run dev
```

Abrí http://localhost:3000. Para producción: `npm run build` y deploy en Vercel.

El dominio público se define con `NEXT_PUBLIC_SITE_URL`. Si no está, el sitio usa `https://example.com`.

Los textos viven en `lib/config.ts`.
